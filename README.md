# BiWaveX
---
### Description

BiWaveX is an AVX-512 implementation of the Bi-directional Wavefront Alignment Algorithm (BiWFA). It utilizes the extended registers of AVX-512, from the 256-bit registers of AVX2 to 512 bits, to parallelize certain processes of the algorithm.

##### What is (Bi-directional) Wavefront Alignment Algorithm?
Wavefront Alignment Algorithm, and subsequently, Bi-directional Wavefront Alignment Algorithm is an sequence alignment algorithm, developed by [Marco-Sola et al. (2020)](https://academic.oup.com/bioinformatics/article/37/4/456/5904262 "Fast gap-affine pairwise alignment using the wavefront algorithm")
